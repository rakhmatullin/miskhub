Фиксация ТТР

Письмо уходит текстом: дата и числа по объектам. План всегда равен факту. Можно несколько фиксаций. Утром письма сами уходят с рабочей почты.

Отправитель и расписание

Общие: отправитель, время и дни. Адресаты задаются отдельно в каждой фиксации.

Автоотправка
В выбранные дни недели, после указанного времени. Один раз за дату для каждой фиксации.
Дни

Тема и текст письма задаются в каждой фиксации. Переменные: {date} {name} {objects} {sum} {workers} {itr} {tech} {filename}.

Пароль не пишется в папку data: репозиторий публичный. Он уходит в секрет GitHub TTR_MAIL_PASSWORD. Для Mail.ru лучше пароль приложения: Настройки → Безопасность → Пароли для внешних приложений.

Токен GitHub

Создай на github.com/settings fine-grained токен только для rakhmatullin/miskhub: Contents — Read and write, Actions — Read and write, Secrets — Read and write. Без права Actions кнопка «Отправить сейчас» даёт ошибку Resource not accessible. Токен остаётся в этом браузере.

Текстовая сводка

Выбери одну или несколько дат и получи готовый текст для копирования или отправки адресатам. Формат грамотный, с полными названиями категорий.

Даты

Адресаты берутся из выбранной фиксации. Отправка идёт через тот же механизм, что и обычные письма (без PDF, только текст).

Журнал

Что ушло и какие числа закреплены. Нажми дату, чтобы открыть этот день. Зафиксированные числа больше не меняются.
