Фиксация ТТР v2.8

Утреннее письмо уходит само. Отдельное можно собрать на любые даты, поправить и отправить своим адресатам. На каждое число пишется, сколько человек суммарно.

Отправитель и расписание

Общие: отправитель, время и дни. Адресаты задаются отдельно в каждой фиксации.

Автоотправка
В выбранные дни недели, после указанного времени. Один раз за дату для каждой фиксации.
Дни

Тема и текст ежедневного письма — в карточке фиксации, в «Шаблоне». В {objects} по каждому объекту и за день есть, сколько человек суммарно.

Пароль не пишется в папку data: репозиторий публичный. Он уходит в секрет GitHub TTR_MAIL_PASSWORD. Для Mail.ru лучше пароль приложения: Настройки → Безопасность → Пароли для внешних приложений.

Токен GitHub

Создай на github.com/settings fine-grained токен только для rakhmatullin/miskhub: Contents — Read and write, Actions — Read and write, Secrets — Read and write. Без права Actions кнопка «Отправить сейчас» даёт ошибку Resource not accessible. Токен остаётся в этом браузере.

Шаг 2

Черновик

Шаблон

Здесь переменные. Числа подставляются в черновик. Пустое поле вернётся к обычному тексту.

Письмо: {name} {dates} {days} {sign}. Число: {date} {sum} {workers} {itr} {tech} {objects}. Объект: {number} {object} {workers} {itr} {tech} {sum}. Суммы по всем дням нет.

Текст правился вручную. «Собрать заново» заменит его.

Шаг 3

Куда отправить

Адреса только этого письма. Карточки фиксаций не переписываются.

Своя почта откроет письмо на этом телефоне. Рабочая — ящик Mail.ru, как утренние фиксации. Уйдёт ровно текст черновика.

Журнал

Под каждым днём — подстрочка объекта: шифр, название и свои рабочие, ИТР, техника. Нажми дату, чтобы открыть день.
