MiskHub

Чтобы сайт работал постоянно, нужно один раз залить два HTML-файла в репозиторий.

1. Убери кастомный домен (если редиректит на miskhub.com)

  1. Открой Settings → Pages
  2. Поле Custom domain — сотри всё → Save
  3. Подожди 1–2 минуты, открой в режиме инкогнито

2. Залей приложение

  1. Скачай index.html и sverka-vesov.html
  2. В репо: Add file → Upload files → оба файла → Commit
  3. Открой rakhmatullin.github.io/miskhub
