# MiskHub

Инструменты для инженера ПТО / зам. РП (компания МИСК).

## Постоянная ссылка

**https://rakhmatullin.github.io/miskhub/**

## Быстрый деплой (один раз, ~2 минуты)

1. Скачай актуальные файлы с Google Drive:
   - папка: https://drive.google.com/drive/folders/1tvyEEVy9TbmYxOM_pZJkjSs8-9537d_X
   - нужны: `index.html` и `sverka-vesov.html`
2. Открой https://github.com/rakhmatullin/miskhub
3. **Add file → Upload files** → залей оба файла → Commit changes
4. **Settings → Pages** → Source: Deploy from a branch → branch **main**, folder **/ (root)** → Save
5. Через 1–2 минуты открой: https://rakhmatullin.github.io/miskhub/

Дальше при обновлениях просто заменяешь файлы в репозитории — ссылка не меняется. Закладка на работе — и всё.
