# MiskHub

Инструменты для инженера ПТО / зам. РП (МИСК).

## Открыть

**Постоянная ссылка (после включения GitHub Pages):**  
https://rakhmatullin.github.io/miskhub/

## Файлы

- `index.html` — 3D-граф базы знаний и инструментов
- `sverka-vesov.html` — сверка весов (ОСИГ ↔ подрядчик)

## Включение GitHub Pages (один раз)

1. Открой https://github.com/rakhmatullin/miskhub/settings/pages
2. Source: **Deploy from a branch**
3. Branch: **main** / folder **/ (root)**
4. Save

Через 1–2 минуты сайт будет доступен по ссылке выше.
