## Сборка актов

Откройте [«Замечания» v2.13](./sborka.html) в Chrome или Edge и выберите рабочую папку. Справочник `ответственные.json` и назначения `назначения.json` автоматически сохраняются в этой папке. Запись из вкладок одного браузерного профиля и адреса синхронизируется браузером. При переходе на другой профиль, адрес или версию сначала закройте рабочую папку в текущей.

Перед нажатием «Открыть в v2.13» можно скачать ZIP-копию рабочей папки, включая выгрузки, фотографии и шаблоны. При ошибке чтения восстановите указанный файл из копии и нажмите «Повторить открытие». Для больших папок можно заранее сделать копию через Проводник.

Переключатель в шапке открывает [архивные v2.8](./sborka-v2.8.html), [v2.9](./sborka-v2.9.html), [v2.10](./sborka-v2.10.html), [v2.11](./sborka-v2.11.html) и [v2.12](./sborka-v2.12.html). При сохранённом разрешении браузер может открыть ранее выбранную папку автоматически. Если он запросит доступ, выберите ту же папку. В архивной v2.8 сохраняется исходное поведение с `document*.xls(x)`. В отсутствие `выгрузка.xlsx` она может удалить старые выгрузки. Начиная с v2.9 эти файлы сохраняются.

В опубликованном MISKHub кнопка «Обновить реестр» использует расширение Экзона v0.3.0. Если папка или ссылка ещё не сохранены, откроется «Экзон». Готовая выгрузка записывается в рабочую папку «Замечаний» как `реестр-экзон.xlsx` либо `реестр-экзон.xls` и сразу отображается в инструменте. Исходный ручной файл сохраняется. При открытии папки инструмент сравнивает дату ручной выгрузки с датой файла `реестр-экзон` и открывает свежий реестр.

В таблице незакрытых актов интеграционный номер указан в скобках после основного. Столбец «Даты» показывает дату предписания и срок устранения в двух строках. Для описаний длиннее пяти строк доступна кнопка «Развернуть».

### Фото и PDF

Для добавления нескольких фотографий и PDF нажмите «+» в нужной строке и выберите файлы. Вставленные страницы PDF сохраняются в рабочей папке как отдельные JPEG в исходном порядке. Фото и эти страницы можно удалять по одному. Для импорта PDF используйте страницу MISKHub или локальный HTTP-сервер. Старые фотографии с именами вида 125_1.jpg и 125_2.jpg открываются в соответствующих строках.

В конце каждой строки кнопка «⋯» открывает действия для замечания. «Скачать» формирует Word-акт этой строки. Отметка «СКП» сохраняется в рабочей папке и добавляет в Word-акт два приложения с новой страницы. Первый ряд вложений попадает в приложение 1 «Фотоматериалы», второй — в приложение 2 «Акт приема-передачи». При снятой отметке изображения идут подряд в одном приложении.

В PDF-журнале все миниатюры помещаются в строке на обложке, а полные наборы изображений размещаются на первой странице каждого замечания. Если описание длинное, текст продолжается на следующих страницах.

### Следующее обновление

Обновляйте номер версии изменённого инструмента MISKHub и сохраняйте доступ к его предыдущей рабочей версии. Зафиксируйте её страницу, скрипты и версии ресурсов до изменений. Обновите переключатель, а ссылку из MISKHub направьте на текущую версию.

### Проверка

```sh
python -B tests/remarks_browser.py
python -B tests/remarks_attachments_browser.py
python -B tests/remarks_skp_browser.py
python -B tests/remarks_table_browser.py
python -B tests/remarks_exon_browser.py
```

Нужны Chromium, Python Playwright, PyMuPDF и Pillow. Тест проверяет миграцию на тестовой папке с данными в формате v2.8, архивирование, многовкладочную запись, повторный запуск, переключатель версий, содержимое DOCX и PDF на 1, 2 и 55 замечаний. Используется нативное файловое хранилище Chromium с тестовым выбором папки.

## Фиксация ТТР

Каждый день собирает «Фиксация технических и трудовых ресурсов»: дата сегодняшняя, план равен факту, рабочие / ИТР / машинисты берутся из диапазонов. На каждое число в письме пишется, сколько человек суммарно. Отдельное письмо собирается на любые даты, правится и уходит либо с рабочей почты, либо через почту телефона. Настройки и журнал лежат в `data/ttr`. Пароль Mail.ru в репозиторий не пишется — только секрет Actions `TTR_MAIL_PASSWORD`. Письмо отправляет workflow «Фиксация ТТР».

## PDF Master

Склейка PDF в браузере: исходники отдельно, готовые файлы отдельно. Страницы выбираются у каждого куска, файлы клеятся слева или справа в один PDF.

В [PDF Master v2.2](./pdf-master.html) под склейкой открыт редактор страниц. Откройте PDF, нажмите на миниатюру для полноэкранного просмотра и при необходимости скачайте JPEG отдельной страницы. Кнопка «+» вставляет выбранные изображения перед страницей, а действие в панели добавляет их в конец. Кнопка «Собрать PDF» сохраняет весь текущий список в указанном порядке, включая страницы вне текущей области прокрутки.

Миниатюры подгружаются при прокрутке. Сборка копирует исходные страницы без растрирования и обрабатывает файлы в браузере. Открытие защищённых паролем документов редактором не поддерживается. [PDF Master v2.1](./pdf-master-v2.1.html) доступен через переключатель в шапке.

Проверка редактора запускается командой `python -B tests/pdf_pages_browser.py`. Нужны Chromium, Playwright, PyMuPDF и Pillow.


## Экзон

[Страница инструмента v0.3.0](./exon.html) открывает локальное расширение Chrome и Edge. Оно скачивает реестр через штатное действие Экзона на указанной странице замечаний. Ссылка и данные входа сохраняются в зашифрованном файле `MISKHub Экзон/вход.json` в выбранной папке. Ручной вход, установка и скачивание HTML описаны в раскрывающемся разделе. [Исходники и проверки](./tools/exon-addon/README.md).

При выпуске новой версии обновите версию в манифесте и на странице, добавьте ZIP с новым номером в `assets` и обновите ссылку скачивания. Сохраните открытый ключ в манифесте, чтобы идентификатор расширения и хранилище браузера сохранились. [Предыдущая версия v0.2.1](./exon-v0.2.1.html).
