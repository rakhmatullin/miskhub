## Сборка актов

Страница на GitHub Pages. Chrome или Edge. Выбрать папку, ввести номер, акт сохраняется рядом. Шаблон встроен.

## Фиксация ТТР

Каждый день собирает «Фиксация технических и трудовых ресурсов»: дата сегодняшняя, план равен факту, рабочие / ИТР / машинисты берутся из диапазонов. На каждое число в письме пишется, сколько человек суммарно. Отдельное письмо собирается на любые даты, правится и уходит либо с рабочей почты, либо через почту телефона. Настройки и журнал лежат в `data/ttr`. Пароль Mail.ru в репозиторий не пишется — только секрет Actions `TTR_MAIL_PASSWORD`. Письмо отправляет workflow «Фиксация ТТР».

## PDF Master

Склейка PDF в браузере: исходники отдельно, готовые файлы отдельно. Страницы выбираются у каждого куска, файлы клеятся слева или справа в один PDF.


## Экзон

[Страница инструмента](./exon.html) открывает официальный вход и предлагает расширение Chrome и Edge для сохранения HTML открытой рабочей страницы. Логин и пароль вводятся на сайте Экзона. Исходники и тест находятся в [tools/exon-addon](./tools/exon-addon/README.md).

При выпуске новой версии обновите версию в манифесте и на странице, добавьте ZIP с новым номером в `assets` и обновите ссылку скачивания. Предыдущий архив остаётся доступен по его адресу.
