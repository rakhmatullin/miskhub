# MiskHub

Инструменты для инженера ПТО / зам. РП (компания МИСК).

## Открыть

**https://rakhmatullin.github.io/miskhub/**

- Граф: https://rakhmatullin.github.io/miskhub/
- Сверка весов: https://rakhmatullin.github.io/miskhub/sverka-vesov.html

Если раньше был настроен кастомный домен `miskhub.com` — в Settings → Pages очисти поле Custom domain и сохрани.

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | 3D-граф (загрузчик) |
| `sverka-vesov.html` | Сверка весов (загрузчик) |
| `data/*` | Сжатые payload приложения |
