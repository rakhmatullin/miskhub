## Сборка актов

Откройте [«Замечания» v2.9](./sborka.html) из распакованной сборки в Chrome или Edge и выберите рабочую папку. Справочник `ответственные.json` и назначения `назначения.json` автоматически сохраняются в этой папке. Запись из вкладок одного браузерного профиля и адреса синхронизируется браузером. При переходе на другой профиль, адрес или версию сначала закройте рабочую папку в текущей.

Перед нажатием «Открыть в v2.9» можно скачать ZIP-копию рабочей папки, включая выгрузки, фотографии и шаблоны. При ошибке чтения восстановите указанный файл из копии и нажмите «Повторить открытие». Для больших папок можно заранее сделать копию через Проводник.

Переключатель в шапке открывает [архивную v2.8](./sborka-v2.8.html) и [v2.9](./sborka.html). При сохранённом разрешении браузер может открыть ранее выбранную папку автоматически. Если он запросит доступ, выберите ту же папку. В архивной v2.8 сохраняется исходное поведение с `document*.xls(x)`. В отсутствие `выгрузка.xlsx` она может удалить старые выгрузки. v2.9 сохраняет эти файлы.

### Следующее обновление

Обновляйте номер версии изменённого инструмента MISKHub и сохраняйте доступ к его предыдущей рабочей версии. Зафиксируйте её страницу, скрипты и версии ресурсов до изменений. Обновите переключатель, а ссылку из MISKHub направьте на текущую версию.

### Проверка

```sh
python -B tests/remarks_browser.py
```

Нужны Chromium, Python Playwright и PyMuPDF. Тест проверяет миграцию на тестовой папке с данными в формате v2.8, архивирование, многовкладочную запись, повторный запуск, переключатель версий, содержимое DOCX и PDF на 1, 2 и 55 замечаний. Используется нативное файловое хранилище Chromium с тестовым выбором папки.

## Фиксация ТТР

Каждый день собирает «Фиксация технических и трудовых ресурсов»: дата сегодняшняя, план равен факту, рабочие / ИТР / машинисты берутся из диапазонов. На каждое число в письме пишется, сколько человек суммарно. Отдельное письмо собирается на любые даты, правится и уходит либо с рабочей почты, либо через почту телефона. Настройки и журнал лежат в `data/ttr`. Пароль Mail.ru в репозиторий не пишется — только секрет Actions `TTR_MAIL_PASSWORD`. Письмо отправляет workflow «Фиксация ТТР».

## PDF Master

Склейка PDF в браузере: исходники отдельно, готовые файлы отдельно. Страницы выбираются у каждого куска, файлы клеятся слева или справа в один PDF.
