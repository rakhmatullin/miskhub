## Устранение замечаний 2.0

Живой реестр на телефоне и компьютере.

1. Загрузить новую выгрузку Excel — diff новых / закрытых / возвращённых.
2. Закрытые и удалённые не стираются, уходят в скрывашку.
3. Статус команды (X / в работе / ? / Альберту / сфоткать) отдельно от колонки «Статус».
4. Фото ДО и ПОСЛЕ с прогрессом загрузки и поворотом ↺↻. В IndexedDB браузера.
5. Карточка акта — локация, комментарий, слоты фото.

Сборка Word-пакета по-прежнему в инструменте «Акты об устранении».

## Сборка акта

Страница на GitHub Pages. Chrome или Edge. Выбрать папку, ввести номер, акт сохраняется рядом. Шаблон встроен.
