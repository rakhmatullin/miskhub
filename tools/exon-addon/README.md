# Надстройка Экзона v0.1.0

Расширение Chrome и Edge открывает штатный экран входа на `https://exon.exonproject.ru/`. После входа слева внизу рабочей страницы появляется кнопка **«Скачать страницу»**.

## Установка

1. Распакуйте ZIP.
2. Откройте в браузере `chrome://extensions` или `edge://extensions` и включите **«Режим разработчика»**.
3. Нажмите **«Загрузить распакованное расширение»** и выберите папку `exon-addon`, в которой лежит `manifest.json`.
4. Откройте меню расширений, выберите **«Экзон — надстройка»** и нажмите **«Войти в Экзон»**. Введите логин и пароль в форме на самом сайте. Если рабочая вкладка была открыта до установки, обновите её.

## Скачать страницу для следующего этапа

Нажмите **«Скачать страницу»** на нужном экране Экзона. Браузер сохранит файл `экзон-….html`. В нём останутся отрисованные тексты, таблицы, названия действий и атрибуты элементов. Копия открывается без скриптов, сетевых ресурсов, значений полей и параметров из ссылок. В ней могут быть видимые рабочие данные. Просмотрите файл перед тем, как приложить его к задаче.

Расширение использует сохранённое почтовое вложение как справку о структуре формы входа. Вход начинается заново на официальном сайте. Данные учётной записи вводятся на стороне Экзона и отсутствуют в исходниках расширения.

## Проверка

`python -B tests/test_extension.py` проверяет в Chromium сценарий на тестовом сайте. Тест охватывает переход со штатной формы на рабочую страницу, скачивание HTML и исключение значений полей и параметров. Скрипты тестируются напрямую, поскольку управляемая среда блокирует установку распакованных расширений. Требуются Python Playwright и Chromium. Для другого пути к Chromium задайте переменную `CHROMIUM`.
