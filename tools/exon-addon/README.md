# Надстройка Экзона v0.4.0

## Установка

1. Распакуйте ZIP в отдельную папку.
2. В Chrome или Edge откройте `chrome://extensions` или `edge://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `exon-addon` с файлом `manifest.json`. При обновлении с v0.1.0 отключите предыдущую копию расширения.
4. Откройте инструмент из MISKHub или через значок «Экзон — надстройка» в браузере.

При обновлении с v0.2.x или v0.3.0 распакуйте новый ZIP поверх установленной папки `exon-addon`. Затем нажмите «Перезагрузить» на карточке расширения. Установленная копия и ключ к файлу входа сохранятся.

## Скачать реестр

Вставьте ссылку раздела «Замечания» на `exon.exonproject.ru`. Если Экзон потребует вход, расширение заполнит его штатную форму. Если Экзон запросит дополнительное подтверждение, завершите вход в открытой вкладке. Затем расширение снимет фильтры, выберет все строки и нажмёт «Выбрать действие» → «Скачать в XLS». Если при общем выделении меню действий не появляется, расширение отмечает строки по отдельности. Для таблиц с несколькими страницами оно проверяет полноту выделения перед скачиванием. Если Экзон сбрасывает выбор при переходе между страницами, инструмент сообщит, что полную выгрузку подтвердить не удалось.

«Выбрать папку» создаёт подпапку `MISKHub Экзон`. «Сохранить настройки» записывает ссылку и данные входа в `вход.json`, зашифрованный AES-GCM. При скачивании с выбранной папкой настройки также сохраняются. Ключ хранится в профиле браузера для этого расширения. При смене профиля заново введите данные и сохраните их в другой папке. Браузер может запросить разрешение на доступ к папке.

После настройки на опубликованной странице «Замечаний» нажмите «Обновить реестр». Расширение получает штатную выгрузку и интеграционные номера из списка. Для незакрытых замечаний сведения о вложениях читаются пакетами в одной вкладке Экзона. Расширение запрашивает только недостающие фото и PDF. Вкладка закрывается после завершения запроса, ошибки или отмены. Ссылка и данные входа остаются в расширении. Файлы больше 32 МБ можно скачать вручную в Экзоне и открыть или добавить в «Замечаниях».

## Сохранить HTML страницы

Внизу инструмента раскройте «Скачивание HTML и ручной вход». На рабочей странице Экзона нажмите «Скачать страницу» в левом нижнем углу. Если вкладка была открыта до установки, обновите её. Браузер сохранит HTML с видимыми текстами, таблицами и названиями кнопок. Просмотрите копию перед отправкой, если на странице есть рабочие данные.

## Проверка

```sh
python -B tools/exon-addon/tests/test_extension.py
python -B tools/exon-addon/tests/test_remarks_export.py
```

Тесты используют Chromium, Python Playwright и Node.js. Они проверяют скачивание HTML, шифрование локального файла, вход на тестовой форме и скачивание XLS с выбором всех строк. Управляемая политика Chromium запрещает установку распакованных расширений, поэтому Chrome API в этих тестах моделируется, а файловые операции и загрузки выполняются браузером.
