# Данные акта ТТР

Папка инструмента «Акт фиксации технических и трудовых ресурсов».

- `settings.json` — диапазоны рабочих / ИТР / машинистов, время, адресаты, тема и текст письма.
- `journal.json` — числа по датам и статус отправки. Зафиксированный день больше не переигрывается.
- `template.pdf` — бланк УДМС. Меняются только дата и числа, подписи остаются.
- Пароль Mail.ru сюда не пишется. Он хранится в секрете репозитория `TTR_MAIL_PASSWORD` и доступен только GitHub Actions.
