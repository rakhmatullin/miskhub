# Токены шаблона акта

Оставляй токен целиком в одном фрагменте (не рви жирным середину).

| Токен | Источник |
|--------|----------|
| `{{НОМЕР-АКТА}}` | колонка Номер |
| `{{ИНТЕГРАЦИОННЫЙ-НОМЕР}}` | интегр. номер или тот же номер |
| `{{ДАТА-ПРЕДПИСАНИЯ}}` | столбец Дата, дд.мм.гггг |
| `{{ДАТА-ПРЕДПИСАНИЯ-ТЕКСТ}}` | «14» сентября 2026г. |
| `{{ДАТА-АКТА}}` | дата комплекта из UI |
| `{{ДАТА-АКТА-ТЕКСТ}}` | «15» сентября 2026 |
| `{{СРОК-УСТРАНЕНИЯ}}` | дата срока без «+ N дн.» |
| `{{ОПИСАНИЕ}}` | столбец Описание |
| `{{ВИД-РАБОТ}}` | вид работ |
| `{{АВТОР}}` | автор |
| `{{ОТВЕТСТВЕННЫЙ}}` | ответственный |
| `{{ПРИОРИТЕТ}}` | приоритет |
| `{{СТАТУС}}` | статус выгрузки |

Фото в шаблон не подставляются. Имена файлов: `N_1` до, `N_2` после.
