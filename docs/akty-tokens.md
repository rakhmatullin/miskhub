# Токены шаблона актов

Подстановка идёт только в `word/document.xml` (и колонтитулы). `word/settings.xml` и прочий пакет не переписываются — иначе Word пишет «не удаётся открыть файл».

Целые токены, один run:

- `{{НОМЕР-АКТА}}`
- `{{ИНТЕГРАЦИОННЫЙ-НОМЕР}}`
- `{{ДАТА-ПРЕДПИСАНИЯ}}` — дд.мм.гггг из столбца «Дата»
- `{{ДАТА-ПРЕДПИСАНИЯ-ТЕКСТ}}` — «09» июля 2026г.
- `{{ДАТА-АКТА}}` — дата комплекта
- `{{ДАТА-АКТА-ТЕКСТ}}` — «17» сентября 2026
- `{{СРОК-УСТРАНЕНИЯ}}` — дата без хвоста «+ N дн.»
- `{{ОПИСАНИЕ}}`
- `{{ВИД-РАБОТ}}`
- `{{СТАТУС}}`

Перед `№ N по объекту` перенос строки из шаблона снимается.

Если после сборки в XML остался `{{…}}`, файл не отдаётся.
